Preparing Linux Environment
Были изучены базовые этапы подготовки Linux сервера:

1) обновление системы

2) установка Git

3) установка Docker

4) установка NGINX

Используемые команды

Обновление системы:

sudo apt update
sudo apt upgrade


Установка Git:

sudo apt install git


Установка Docker:

sudo apt install docker.io
