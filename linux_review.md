Linux Distribution Review
Рассматриваемые дистрибутивы

Для проекта я  рассмотрел следующие Linux дистрибутивы:

1) Ubuntu Server

2) Debian

3) CentOS

И наиболее подходящим был выбран Ubuntu Server.

Причины выбора Ubuntu

1) простая установка

2) большое количество документации

3) поддержка Docker и NGINX

4) удобство для DevOps задач

Вывод

Ubuntu является хорошим выбором для учебного backend и DevOps проекта.
