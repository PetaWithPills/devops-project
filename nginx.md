NGINX

Для проекта я настроил NGINX в Docker.
Как я понял NGINX используется как reverse proxy между клиентом и backend приложением.

Настроен файл nginx.conf который перенаправляет запросы на backend контейнер.

После запуска через Docker Compose приложение стало доступно по адресу:

http://localhost/users

Настройка прошла успешно и результатом стало взаимодействие NGINX с backend приложением.
