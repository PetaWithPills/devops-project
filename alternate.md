Alternate Launch Methods
Были рассмотрены различные способы запуска backend приложения:

1) обычный запуск через Node.js

2) запуск через Docker

3) запуск через Docker Compose

Обычный запуск backend

npm run dev


Запуск через Docker Compose

docker compose up --build


Вывод

Docker Compose сильно упрощает запуск multi-container приложений.
