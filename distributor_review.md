Hosting Provider Review
Рассматриваемые провайдеры

Для размещения проекта я рассматривал:

1) DigitalOcean 

2) AWS

3) Google Cloud

4) Timeweb Cloud

Что изучалось

Были изучены:

1) стоимость VPS

2) удобство панели управления

3) поддержка Docker

4) доступность Linux серверов

Для учебного проекта наиболее подходящим показался DigitalOcean.

Вывод

Облачные VPS провайдеры подходят для размещения backend приложений и DevOps практики.
